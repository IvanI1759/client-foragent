# Project Brief

## Цель проекта

Telegram-бот — AI-ассистент для предпринимателей и их команд. Владелец бота (основатель) выдаёт доступ партнёрам через команду `/grant`. Партнёры используют 4 специализированных ИИ-агента как рабочий инструмент для маркетинга, копирайтинга, рекламы и упаковки продуктов.

## Для кого

- **Владелец бота** — предприниматель, управляет доступом, загружает базу знаний (RAG), контролирует расход API
- **Партнёры** — получают доступ по user_id, работают с агентами в рамках своих задач

## Ключевые сценарии

1. **Онбординг партнёра**: владелец отправляет `/grant {user_id}` → партнёр запускает `/start` → видит меню агентов
2. **Работа с агентом**: партнёр выбирает агента → отправляет вопрос → бот отвечает с учётом базы знаний (RAG)
3. **Загрузка документов**: владелец отправляет `/upload` + файл → бот разбивает на чанки → создаёт embeddings → сохраняет в pgvector
4. **Повторная загрузка**: при `/upload` с существующим filename — старые чанки удаляются, новые загружаются
5. **Контроль расхода**: глобальный счётчик Gemini API, при 80% — предупреждение владельцу, при 100% — заглушка пользователям
6. **Отказ в доступе**: незарегистрированный пользователь видит свой user_id и инструкцию отправить его администратору

## Бизнес-ограничения

- Бесплатный тариф Render (512MB RAM, sleep после 15 мин неактивности)
- Gemini API — лимит запросов в день (настраивается через env)
- При росте нагрузки — миграция на Railway
- Минимальные зависимости, простая архитектура для одного разработчика
