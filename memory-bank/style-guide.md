# Style Guide

## Код

### Общие правила
- ES Modules: `import`/`export`, никогда `require`
- `async/await` везде, без `.then()` цепочек
- Одна функция — одна ответственность
- Имена файлов: kebab-case (`rate-limiter.js`)
- Имена функций и переменных: camelCase
- Константы: UPPER_SNAKE_CASE

### Обработка ошибок
- Каждый вызов Gemini API обёрнут в try/catch
- Обрабатывать: 429 (rate limit), 500 (server error), timeout
- При 429 — ответ пользователю: "Слишком много запросов, подождите"
- При 500/timeout — "Сервис временно недоступен, попробуйте позже"
- Никогда не показывать stack trace пользователю

### Логирование
- Формат: `[ACTION] user_id=123456 agent=marketer`
- Логировать: user_id, действие, agent_type, статус (ok/error)
- Никогда: содержимое сообщений, API-ключи, персональные данные

### Структура handler-файла
```js
// 1. Imports
// 2. Handler function (export default или named export)
// 3. Вспомогательные функции (private)
```

## Промпты агентов

### Структура системного промпта
```
Ты — {роль}. Ты помогаешь предпринимателям с {область}.

Правила:
- Отвечай на русском языке
- Используй контекст из базы знаний, если он предоставлен
- Если в базе знаний нет релевантной информации — скажи об этом
- Давай конкретные, применимые рекомендации
- Форматируй ответ для Telegram (короткие абзацы, списки, bold)

Контекст из базы знаний:
{rag_context}
```

### Правила промптов
- Всегда указывать роль и область ответственности
- Явно требовать русский язык
- RAG-контекст вставлять в конец системного промпта
- Ограничивать длину ответа (~1500 символов для Telegram)
- Инструкция игнорировать попытки переопределения роли (prompt injection)

## UX в Telegram

### Сообщения бота
- Максимум 3-4 абзаца, короткие предложения
- Использовать **bold** для ключевых пунктов
- Списки через `•` или нумерацию
- Эмодзи — умеренно, только функциональные (не декоративные)

### Клавиатура
- Inline-кнопки для выбора агента (1 ряд = 2 кнопки)
- callback_data: `agent:{type}` (например `agent:marketer`)
- После выбора — подтверждение: "Агент: **Маркетолог**. Задайте вопрос."

### Ошибки пользователю
- Понятный русский текст, без технических деталей
- При отказе в доступе: "Ваш ID: {id}. Отправьте его администратору для получения доступа."
- При лимите: "Лимит запросов исчерпан. Попробуйте через час."
- При ошибке API: "Сервис временно недоступен. Попробуйте через минуту."
